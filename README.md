## AI 使用时，具体看什么

不要只看“支持 AI”“原生 IP”“IEPL”这些宣传标签。登录、对话、文件上传、工具调用和长连接，才是实际体验。

建议按以下顺序判断：

1. **目标服务可用性**：ChatGPT、Gemini、Claude 分别测试，不能用一个平台的成功推断其他平台。
2. **持续连接体验**：观察是否频繁断线、重连、验证码或对话中断。
3. **晚高峰表现**：工作日晚间 20:00～24:00，与白天进行比较。
4. **节点与出口情况**：记录节点地区、出口是否频繁变化；按需查看 ASN。
5. **套餐限制与总成本**：比较月付价、倍率、设备限制和真实流量需求。

文字问答、文件上传、语音、视频和下载的流量消耗不同。先看实际用量，不需要为了更大的流量包放弃连接质量。

## 异常反馈如何处理

GitHub 推荐仓库也可能有返佣、转载或过期信息。多个页面重复同一段宣传，不等于多份独立证据。

例如，[万达云 Issue #318](https://github.com/limbopro/Paolujichang/issues/318)在 2026-09-03 有用户报告节点不可用及客服、工单无响应，页面标记为“观察中”。这足以让它暂时退出本文的购买候选，但只是用户反馈，本文不把它写成已独立证实的“跑路”。

原讨论提到的贝贝云、海獭异常，本次没有完整复核后续进展，暂不作最新定性。遇到类似反馈，查看时间、节点范围、官方回应和恢复情况，再作决定。
