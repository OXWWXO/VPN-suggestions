# 常见问题与术语

[← 返回首页](../README.md) · [从零开始](getting-started.md) · [测试方法](testing.md)

## 客户端、机场、节点分别是什么？

客户端是你设备上的软件；机场在这里指提供订阅和代理线路的服务；节点是具体可选择的连接端点。客户端免费不代表商家的线路免费，安装软件也不会自动得到可用订阅。

## 为什么不按测速从快到慢排序？

首页资料来自不同作者、宽带、测试后端、线程数与日期。把它们直接排成统一榜单会掩盖条件差异。选主力更应看自己的常用时段和任务是否连续可用。

## 能看视频就能用 AI 吗？

不能这样推断。不同服务有不同网络、地区和账号要求。同一个服务也要分开看首页、登录、消息、上传和桌面端。页面已有历史样本不代表今天所有节点仍可用。

## 年付更便宜，为什么先试月付？

折算价低需要一次支付更高金额；本地接入和服务需求还没验证时，先用支持的小额周期取得自己的结果。是否退款、能否升级和剩余流量怎么处理，要在付款前查规则。

## 住宅、原生、独享、静态有什么区别？

| 术语 | 在选购时关注什么 |
| --- | --- |
| 住宅 / 家宽 | IP 的网络归属与数据库标注；不能据标签推断所有平台认可 |
| 原生 | 商家使用的地区归属描述，需询问具体定义与检测来源 |
| 独享 | 是否仅由你使用出口 IP，还是仅独享账号或端口 |
| 静态 | 目标网站看到的出口是否固定；维护换 IP 条款另查 |
| IEPL / IPLC | 服务方的专线描述；没有链路证据时按宣传信息记录 |
| 直连 / 中转 | 是否通过中间入口接入；体验仍取决于实际路由和时段 |
| FUP | 公平使用规则，包括流量、带宽或并发阈值及超额处理 |

需要固定出口可看[静态 ISP 术语](https://github.com/OXWWXO/static-isp-guide/blob/main/docs/glossary.md)，不要仅凭营销标签购买。

## 为什么节点显示可用，浏览器仍失败？

延迟测试访问的是特定测试地址。浏览器可能没走系统代理，也可能被扩展覆盖，或者失败请求走了其他策略组。先在连接面板找目标域名，再查所用节点与错误。TUN 的作用和权限按客户端官方文档确认。

## 官网入口为什么带 code？

本仓库部分商家入口含邀请码或推广参数，具体权益和返利规则由商家决定。原始评测也可能有商业合作。读者可以自行寻找并核验无邀请码入口；排序应结合证据和自己的使用结果判断。

## 如何反馈价格过期或使用异常？

从 [Issue 模板](https://github.com/OXWWXO/VPN-suggestions/issues/new/choose)选“价格与资料更正”或“使用体验”。提交日期、来源和场景，密码、订阅 URL、订单和 Cookie 留在本地。模板不会要求上传这些凭据。
