# 第一次使用：从选购到验证

[← 返回首页](../README.md) · [测试记录方法](testing.md) · [常见问题与术语](faq.md)

不需要先研究完十五家。按下面的顺序，把自己的需求缩小到一两家，再做小额测试。

## 1. 写下三个条件

| 条件 | 你要填什么 | 为什么先填 |
| --- | --- | --- |
| 每次付款上限 | 例如 20 元，而不是“折合每月 20 元” | 年付折算价不等于月付可买 |
| 主要用途 | AI 对话、视频、下载、多地区中的一两项 | 不同用途要看的证据不同 |
| 使用环境 | 本地运营商、设备、常用时间 | 他人的测速不能代替你的接入环境 |

只需要偶尔打开网页时，先试现有入口。需要稳定保留固定出口时，再阅读[静态 ISP 配套指南](https://github.com/OXWWXO/static-isp-guide)；它会增加一份费用和一层配置。

## 2. 缩小到一两家

从[用途卡片](../README.md#quick-picks)进入，随后看该家的“优势与不足”和原始资料。比较时把下面几项放在同一张纸上：

- **实付金额**：首次付款多少，租期多久，续费是否同价。
- **流量周期**：每月重置、每 30 天重置，还是一次性总流量。
- **使用限制**：设备、并发、公网 IP 数、运营商、IPv6 和退款条件。
- **证据日期**：套餐记录和测速可以来自不同日期，要分别看。

如果只能看到最低价宣传，找不到实际套餐规则，先把它放在待确认项。首页推荐顺序是选购判断，没有把十五家放进相同环境进行统一排名。

## 3. 从官方来源安装客户端

| 客户端 | 官方入口 | 平台与阅读重点 |
| --- | --- | --- |
| Clash Verge Rev | [项目与下载](https://github.com/clash-verge-rev/clash-verge-rev) · [文档](https://www.clashverge.dev/) | Windows / macOS / Linux；订阅、代理选择、连接面板 |
| v2rayN | [项目与下载](https://github.com/2dust/v2rayN) · [Wiki](https://github.com/2dust/v2rayN/wiki) | Windows / macOS / Linux；发布包选择、导入订阅、系统代理 |
| sing-box（进阶） | [项目](https://github.com/SagerNet/sing-box) · [文档](https://sing-box.sagernet.org/) | 按官方客户端列表选平台；需理解配置格式与路由 |

客户端支持的协议、订阅格式和系统版本以各自官方文档为准。商家给的通用订阅不一定能直接交给任意客户端或 Mihomo provider。

**订阅 URL 相当于访问凭据。** 复制到本地客户端即可；截图、Issue、在线转换网站和聊天记录中不要公开它。

### 以 Clash Verge Rev 为例：第一次导入

1. 从官方 Releases 下载对应操作系统与 CPU 架构的安装包，安装并打开。
2. 登录商家后台，在“订阅 / 客户端导入”等入口找到适用于 **Clash / Mihomo** 的订阅，复制它的 URL。不要复制浏览器里的商家首页地址。
3. 打开客户端“订阅”页，把 URL 填入导入栏并导入；版本界面不同则新建远程订阅并填写 URL。确认更新成功并选中这份订阅。
4. 到“代理”页，为常用服务的策略组选择一个具体节点。初次测试避免只看自动选择组的名称而不知道实际用了哪个节点。
5. 在“设置”中启用系统代理，然后打开浏览器访问一个普通网页；在“连接”页核对相应请求。系统代理通常不自动接管所有桌面程序和终端。
6. 按下一节测试实际用途。导入失败时先核对订阅是否过期、格式是否匹配和地址是否复制完整，再参考[官方文档](https://www.clashverge.dev/)。

## 4. 先验证连接，再验证用途

1. 导入订阅并更新，确认套餐未过期、流量未用完。
2. 选择一个具体节点，开启客户端需要的系统代理；确认浏览器请求出现在连接面板中。
3. 先打开普通网页，再试实际要用的服务。
4. AI 用途分别试登录、发消息、流式响应和上传；视频用途记录清晰度、缓冲和掉速时段。
5. 白天和晚高峰分别使用，按[记录模板](testing.md#记录模板)保留结果。

节点延迟数字只反映测试地址的响应。延迟低、测速快、首页能打开，都不能单独证明完整功能可用。

## 5. 按结果决定续费

| 结果 | 下一步 |
| --- | --- |
| 普通网页也不通 | 查客户端是否接管、订阅、套餐与入口节点 |
| 网页正常，特定服务失败 | 记录失败域名和提示，换同家其他地区节点对照 |
| 白天好、晚间差 | 连续几个时段复查；主力选择更看重常用时段 |
| 常用功能持续可用 | 按真实流量需求续费，不必为最大档提前付款 |
| 需要固定 ISP 出口 | 先验证入口，再按[链式配置](https://github.com/OXWWXO/static-isp-guide/blob/main/docs/clash-verge.md)测试第二跳 |

不要只因一次失败就连续购买多家。先把问题缩小到客户端、入口、目标服务或账号，再决定是否更换。
